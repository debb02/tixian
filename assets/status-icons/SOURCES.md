# Status icon references

- Apple: https://developer.apple.com/design/human-interface-guidelines/status-bars
- Android / Pixel system bars: https://developer.android.com/design/ui/mobile/guides/foundations/system-bars
- Samsung One UI design: https://developer.samsung.com/one-ui/index.html
- Xiaomi HyperOS system-bar behavior: https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1629

Apple and Android document the system-bar role and platform behavior. Android explicitly notes that system bars vary by device manufacturer. Samsung, Xiaomi, and vivo do not publish downloadable raw status-bar glyph packs; their folders are isolated so a reference-confirmed asset can replace one brand without affecting the others.
